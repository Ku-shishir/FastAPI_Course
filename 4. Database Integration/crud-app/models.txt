11. Why do we use models instead of writing SQL?

Without SQLAlchemy, you might write:

CREATE TABLE employees (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100) UNIQUE
);

With SQLAlchemy ORM, you define:

class Employee(Base):
    __tablename__ = "employees"

    id = Column(Integer, primary_key=True)
    name = Column(String)
    email = Column(String, unique=True)

SQLAlchemy handles the database interaction for you.

That's why it is called ORM — Object Relational Mapping.

Python Object/Class          Database
       │                        │
       │       ORM              │
       └────────────────────────┘
             SQLAlchemy
