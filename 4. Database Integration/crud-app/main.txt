10. get_db() — Database Dependency

This is one of the most important parts of your main.py.

Your code:

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

Let's understand it.

Step 1
db = SessionLocal()

Creates a new database session.

SessionLocal()
     ↓
Database session
Step 2
yield db

Gives that database session to the API endpoint.

For example:

db: Session = Depends(get_db)
Step 3

After the request is finished:

finally:
    db.close()

closes the database session.

This is important because you don't want unused database sessions remaining open.

11. Why use yield?

This is a common interview question.

You use:

yield db

because you want to:

Create the database session.
Give it to the endpoint.
Perform the database operation.
Close the session after the request.

Think:

Request starts
     ↓
Session created
     ↓
yield db
     ↓
Endpoint uses DB
     ↓
Request finishes
     ↓
db.close()
